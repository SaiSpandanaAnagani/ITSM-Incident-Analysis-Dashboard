ITSM Incident Analysis Dashboard

Project Overview

An interactive Excel dashboard developed to analyze 3,000 ITSM tickets across Incident Management (INM), Problem Management (PRM), and Service Request Management (SRM).

The project focuses on SLA compliance, ticket resolution performance, operational KPIs, and service delivery insights.

Key Business Insights

Analyzed 3,000 ITSM tickets.

Achieved 83.73% SLA compliance among tickets with completed SLA outcomes.

PRM recorded the highest number of SLA breaches.

P4 tickets contributed the highest number of SLA breaches.

SRM had the highest average resolution time at 36.86 hours.

Business Recommendations

Strengthen proactive SLA monitoring.

Improve ageing-based ticket follow-ups.

Optimize team workload distribution.

Improve first-time resolution.

Conduct root-cause analysis to reduce recurring incidents.

Project Objective

To convert operational ITSM ticket data into actionable business insights and improve SLA performance and service delivery efficiency.
